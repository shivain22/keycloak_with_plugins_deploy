## Database Types Supported

1. **PostgreSQL** - Port 5432 (Default)
2. **MySQL** - Port 3306
3. **Oracle** - Port 1521
4. **Microsoft SQL Server** - Port 1433
5. **IBM DB2** - Port 50000

## How It Works

### Backend Flow
1. User selects database type in frontend
2. Frontend sends `databaseType` field in tenant creation request
3. `TenantService` validates the database type
4. If not provided, defaults to POSTGRESQL
5. Database type is stored in `tenants.database_type` column

### Frontend Flow
1. User sees database type dropdown in tenant creation form
2. Selecting a database type:
   - Updates the preview database URL
   - Shows the correct default port
3. On form submission, database type is included in the request
4. Auto-generated fields reflect the selected database type

## Database URL Format

The system generates JDBC URLs based on the selected database type:
- **PostgreSQL**: `jdbc:postgresql://localhost:5432/rms_{tenantKey}`
- **MySQL**: `jdbc:mysql://localhost:3306/rms_{tenantKey}`
- **Oracle**: `jdbc:oracle://localhost:1521/rms_{tenantKey}`
- **MSSQL**: `jdbc:mssql://localhost:1433/rms_{tenantKey}`
- **DB2**: `jdbc:db2://localhost:50000/rms_{tenantKey}`
